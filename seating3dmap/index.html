What it is

A new map type
for UrVenue microsites

The venue in 3D, so guests can choose and book their place: a cabana, a table or a daybed.

Built with three.js on top of the seating3dmap API
Independent from the 2D seating map that already exists
Lives in uvcore: new page, no global changes
English, Spanish and Japanese from day one
